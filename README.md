# Open-HCI

## 安裝

### 1. Clone Repository

```bash
git clone https://github.com/<your_username>/<repo_name>.git
cd <repo_name>
```

### 2. 建立虛擬環境

Windows：

```bash
python -m venv venv
venv\Scripts\activate
```

Linux：

```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. 安裝套件

```bash
pip install -r requirements.txt
```
